# Relief_Creator
Это проект для создания барельефа картинок (например монеты)

## Подготовка окружения
Разрабатывалось под версию python 3.12.0
- Создайте виртуальное окружение:
```
python -m venv venv
```
- Установите необходимые зависимости
```
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt
```

## Использование
В директории input можете хранить исходные картинки

В файле `main.ipynb` находится весь код приложения.
В разделе `# 6. Загрузка тестового изображения` измените значение `example_path` на путь до вашей картинки.

## Картинки

Если открываете в vs-code, то в разделе `# 11. Интерактивная 3D визуализация В VS CODE` Будет красивая 3D модель, которую можно повращать мышкой.

Если же возможности открыть в vs-code нет, то в папке `output_3d_visualization` лежит interactive.html файлик, который можно открыть в любом браузере и у вас отобразиться то же самое, что и в vs-code
